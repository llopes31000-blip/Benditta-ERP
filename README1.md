# Benditta ERP

Sistema de gestão desenvolvido exclusivamente para a Benditta Pastelaria, com foco em controle de produtos, custos, estoque, pedidos e análise de vendas.

## 🎯 Objetivo do Projeto

Criar uma plataforma própria para gerenciamento completo da operação da pastelaria, permitindo:

- Controle de produtos do cardápio
- Gestão de ingredientes
- Formação automática de preços
- Controle de custos
- Controle de estoque
- Gerenciamento de pedidos
- Análise de vendas e lucratividade

O sistema será desenvolvido pensando na realidade de uma operação de alimentação, com possibilidade de expansão futura para integração com marketplaces e aplicativos.

# 🚀 Roadmap do Projeto

## Versão 1.0 - Gestão Básica

Status: Em desenvolvimento

### Produtos
- Cadastro de pastéis
- Cadastro de salgados
- Cadastro de bebidas
- Cadastro de adicionais
- Categorias do cardápio

### Custos
- Cadastro de ingredientes
- Controle de preço por unidade/kg
- Cálculo automático de custo do produto
- Margem de lucro

### Estoque
- Entrada de ingredientes
- Baixa automática por venda
- Alertas de estoque baixo
